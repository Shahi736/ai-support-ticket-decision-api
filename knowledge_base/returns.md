# Returns Policy

## Return Window
Customers may return most items within 15 days of delivery for a full refund or exchange, provided the item is unused and in original packaging.

## Restocking Fee
A 10% restocking fee applies to returns of electronics and appliances, unless the item was defective on arrival.

## Return Shipping
- If the return is due to a company error (wrong item shipped, defective product), the company covers return shipping costs.
- If the return is due to customer preference (changed mind, wrong size ordered), the customer covers return shipping costs.

## How to Initiate a Return
Customers must request a return authorization through their account before shipping the item back. Items returned without authorization may be refused.

## Exchanges
Exchanges for a different size or color are processed as a return + new order, and follow the same 15-day window.
